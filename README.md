
# 📊 소비컷 (Consumer Cut)

> 감정 기반 소비 분석으로 충동 소비를 줄이는 대학생 맞춤형 스마트 가계부

---

## 📌 프로젝트 소개

기존 가계부 앱은 단순한 지출 기록에 그쳐
**“왜 소비했는지”**에 대한 맥락을 제공하지 못합니다.

본 프로젝트는
사용자의 소비 데이터 + 감정 태그를 기반으로

* 충동 소비를 정량적으로 분석하고
* 또래와의 비교를 통해 소비 수준을 인지하며
* 행동 변화를 유도하는

**데이터 기반 소비 분석 서비스**입니다.

---

## 🎯 목표

> 대학생이 **충동 소비를 스스로 인식하고 패턴을 교정**할 수 있도록 돕는다.

---

## 🔥 핵심 기능

### 1. 📒 스마트 가계부

* 카드 문자 자동 파싱 → 지출 자동 기록 (신한/삼성/현대/KB국민/카카오뱅크/NH농협/우리카드 지원)
* 날짜 / 시간 / 금액 / 사용처 자동 입력
* 카테고리 자동 분류 (룰 매칭 → 가맹점 캐시 → Claude API fallback 순으로 판정)
* 자유 텍스트 소비 태그 — 심리특성 태그와 별개로 메모하듯 자유롭게 남기는 태그 (기록용, 충동 점수엔 미반영)

👉 수동 입력 최소화 → 지속 사용 유도

---

### 2. 🧠 구매 결정 심리특성 분석

소비 시 심리특성 태그 다중 선택 (5개 중 최대 4개, 중복 불가)

* 스트레스 / 즉흥성 / 비교회피
* 충분한숙고 / 장기적가치

👉 "왜 그렇게 결정했는지"를 데이터로 기록

---

### 3. ⚠️ 충동 소비 점수 (충동 위험 지수)

로지스틱 회귀 기반 계산 (설문조사 기반 충동 점수 로직 재설정, 대학생 45명 설문 반영)

결제 전 위험 점수(실시간):
* 이상 시간대
* 금액 부담 (예산 대비 비율 + 구매 시점 체감 부담)
* 또래 대비 소비 (z-score)
* 심리 변수: 스트레스/즉흥성/비교회피(촉진) · 충분한숙고/장기적가치(억제)

결제 후 평가(참고/개인화용, 실시간 점수엔 미반영):
* 구매 후 후회, 지속적 만족 (1일/7일/30일 만족도 기반)

👉 결과: **충동 위험 지수 (0 ~ 100점)**

* 0~59 낮음 / 60~66 주의 / 67 이상 경고

---

### 4. 📊 소비 패턴 리포트

* 시간/요일별 소비 히트맵 (요일컷·시간대컷 완전 독립 집계)
* 카테고리별 소비 비율
* 감정 기반 소비 분석 (태그 부착 비율 + 태그별 지출 거래 비율, 두 지표 모두 제공)

👉 한눈에 보는 소비 습관

---

### 5. 🧬 소비 성격 유형 (BPTI)

MBTI처럼 소비 유형 제공

예시:

* FIRE 🔥 : 스트레스 소비형
* FOG 🌫️ : 즉흥 소비형
* SAGE 🦉 : 신중한 숙고형

👉 자기 인식 강화

---

### 6. 🌡️ 또래 소비 비교 (지갑 온도)

* 내 소비 vs 또래 평균 비교
* % → 온도(°C)로 시각화

예시:

* 내 지갑: 72°C
* 또래 평균: 65°C

👉 스트레스 없이 상대적 소비 인지

---

### 7. 🎮 게이미피케이션 (소비 정령)

* 소비 습관에 따라 캐릭터 성장

단계:

* 슬라임 커티 → 씨앗 커티 → 박스 몬스터 → 쉴드 가디언 → 위저드 커티 → 나이트 커티 → 금융의 신 커티 (Lv0~6)

👉 재미 + 지속 사용 유도

---

### 8. 💌 AI 주간 소비 처방

매주 월요일, 지난주 소비 데이터를 규칙 기반으로 "팩터 문장"(예: "즉흥성이 달린 소비 3회")으로
요약한 뒤 Claude API로 실천 가능한 처방 3개를 생성

* 거래가 없거나 뽑을 팩터가 없는 주는 LLM 호출 없이 건너뜀 (비용 절약)
* 생성된 처방은 캐싱되어 같은 주에 대해 재생성하지 않음

👉 "이번 주엔 뭘 조심하면 될지" 바로 알려주는 코칭

## 🧠 AI 기능

### 1. 충동 소비 탐지

* 설문조사(대학생 45명) 기반 로지스틱 가중합 공식 — `app/services/weights.json`에 가중치 분리
* 행동 변수(이상 시간대·금액 부담·또래 비교) + 심리특성 태그 결합

---

### 2. 월말 소비 예측

* 일평균 지출 기반 선형 추정 (경과일수 대비 신뢰도 단계 제공)

---

### 3. 카테고리 자동 분류 fallback

* 가맹점명 룰 매칭 실패 시 → 가맹점 캐시 조회 → Claude API 분류 순으로 처리
* 어떤 단계가 실패해도 예외 없이 `category: null`로 안전하게 응답

---

### 4. 주간 소비 처방 생성

* Claude API에 이번 주 소비 팩터를 구조화 출력(JSON Schema)으로 요청해 처방 3개 생성

### 🔔 알림 (4종, 종류별 개별 on/off)

* 예산초과 알림 — 거래 등록 시 실시간 체크 (인앱 + 웹 푸시)
* 충동지수 트렌드 알림 — 건별이 아니라 이번 달 평균 충동 지수가 75/90/99점 단계를
  새로 넘을 때만 1회 발송 (인앱 + 웹 푸시)
* 히트맵 알림 — 요일컷(이번 달 최다 소비 요일, 매일 09:10 KST)과 시간대컷(이번 달 최다
  소비 시간대 진입 시, 매일 06/11/14/19/23시 KST)을 완전히 독립적으로 계산·발송
* 가계부 기록 도우미 — 오늘 지출/수입 기록이 없으면 매일 22:00(KST) 알림
* 만족도 조사 알림 — 고가 소비(5만원↑) 후 1일/7일/30일째 자동 배치, 매일 21:00(KST)
* 웹 푸시 구독/해제 (VAPID)
* (발표/시연용) 위 배치들을 스케줄 대기 없이 즉시 1회 실행하는 수동 트리거
  (`POST /demo/trigger/*`, 호출자 본인 계정에만 적용 — 자세한 건 [docs/api.md](docs/api.md) 참고)

## 🚀 실행 방법

### 1. 환경 설정

```bash
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # DATABASE_URL, SECRET_KEY 수정

# 웹 푸시용 VAPID 키 생성 후 .env에 추가
python scripts/generate_vapid_keys.py

# 카테고리 자동분류 fallback / 주간 소비 처방 기능을 쓰려면 .env에
# ANTHROPIC_API_KEY 추가 (https://console.anthropic.com/settings/keys).
# 미설정 시 두 기능만 조용히 비활성화되고 나머지는 정상 동작함.
```

### 2. DB 마이그레이션

```bash
alembic upgrade head
```

### 3. 서버 실행

```bash
uvicorn app.main:app --reload
```

- Swagger UI: http://localhost:8000/docs (API 명세의 source of truth)

### 4. 테스트

```bash
pytest
```

## 📁 프로젝트 구조

```
app/
├── main.py          # FastAPI 앱 진입점
├── core/            # 설정, JWT 보안, 의존성, 배치 스케줄러(APScheduler), 카테고리 상수
├── db/              # 세션, Base, 시드 데이터(구매 결정 심리특성 5종)
├── models/          # SQLAlchemy 모델 (거래/소비태그/감정태그/예산/만족도/알림/
│                    # 카카오연동/LLM처방/가맹점카테고리캐시 등)
├── schemas/         # Pydantic 요청/응답 스키마
├── services/        # 충동 점수·지갑 온도·BPTI·리포트·레벨·카드문자파싱·카테고리매칭(룰/캐시/LLM)·
│                    # 카카오인증·웹푸시·만족도배치·히트맵배치·기록도우미배치·
│                    # 주간처방생성(Claude)·주간요약·팩터추출 로직
│   └── weights.json # 충동 점수 가중치 (설문 산출값 기반)
└── routers/         # API 라우터 (auth/users/transactions/emotions/budget/satisfactions/
                     # notifications/reports/demo)
alembic/             # DB 마이그레이션
scripts/             # VAPID 키 생성 등 1회성 스크립트
tests/               # pytest 테스트 (127건)
```

> 충동 점수 가중치는 `app/services/weights.json`에 분리되어 있어 코드 수정 없이
> 값만 교체할 수 있습니다. 현재는 설문조사(대학생 45명) 상관계수를 표준화 로짓
> 계수로 변환한 값이며, 실사용 데이터가 쌓이면 로지스틱 회귀로 재추정할 예정입니다.
